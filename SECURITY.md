# Security Policy

## Supported versions

Only the latest released version of fromjcl on PyPI receives security
fixes.

## Reporting a vulnerability

Please do not file public issues for security problems. Report them
privately via one of:

- GitHub's "Report a vulnerability" button on the
  [Security tab](https://github.com/msradam/fromjcl/security/advisories/new)
- Email: msrahmanadam@gmail.com

Please include reproduction steps, the affected version, and any
proof-of-concept input (JCL file or shell snippet).

You should receive an acknowledgement within 7 days. Public disclosure
will be coordinated with the reporter.
