# fromjcl

Convert JCL to modern formats.

```bash
fromjcl job.jcl --to mvscmd     # Shell script for z/OS USS
fromjcl job.jcl --to zoau       # ZOAU shell commands
fromjcl job.jcl --to ansible    # Ansible playbook
fromjcl job.jcl --to json       # Structured JSON
fromjcl job.jcl --to yaml       # Structured YAML
```

## Installation

### From Source

```bash
git clone https://github.com/msradam/fromjcl.git
cd fromjcl
pip install .
```

This builds the C parser extension and installs the `fromjcl` command.

### With uv

```bash
git clone https://github.com/msradam/fromjcl.git
cd fromjcl
uv sync
uv run fromjcl --help
```

### Requirements

- Python 3.10+
- C compiler (for building the parser extension)
- cffi (installed automatically as build dependency)

## Quick Start

**Input** (`test.jcl`):
```jcl
//TESTJOB  JOB (ACCT),'TEST',CLASS=A,MSGCLASS=X
//STEP01   EXEC PGM=IDCAMS
//SYSPRINT DD SYSOUT=*
//SYSIN    DD *
 /* HELLO FROM FROMJCL */
/*
```

**Parse to YAML** (`fromjcl test.jcl --to yaml`):
```yaml
name: TESTJOB
account: (ACCT)
programmer: TEST
class_: A
msgclass: X
steps:
- name: STEP01
  program: IDCAMS
  dds:
  - name: SYSPRINT
    sysout: '*'
  - name: SYSIN
    instream: " /* HELLO FROM FROMJCL */"
```

**Generate and run on z/OS** (`fromjcl test.jcl --to mvscmd | sed 's/mvscmd/mvscmdauth/' | sh`):
```
1IDCAMS  SYSTEM SERVICES                                           TIME: 12:00:00        01/01/25     PAGE      1
0        
  /* HELLO FROM FROMJCL */
0IDC0002I IDCAMS PROCESSING COMPLETE. MAXIMUM CONDITION CODE WAS 0
```

## Query JCL as Data

Convert to JSON and pipe to `jq` for instant insights:

```jcl
//DAILYRPT JOB (ACCT001),'DAILY REPORT',CLASS=A
//STEP01   EXEC PGM=SORT
//SORTIN   DD DSN=PROD.SALES.EXTRACT,DISP=SHR
//         DD DSN=PROD.SALES.HISTORY,DISP=SHR
//SORTOUT  DD DSN=PROD.SALES.SORTED,DISP=(NEW,CATLG),
//            SPACE=(CYL,(100,20)),DCB=(RECFM=FB,LRECL=200)
//STEP02   EXEC PGM=REPORT
//INPUT    DD DSN=PROD.SALES.SORTED,DISP=SHR
//OUTPUT   DD DSN=PROD.DAILY.REPORT,DISP=(NEW,CATLG),
//            SPACE=(TRK,(50,10)),DCB=(RECFM=FBA,LRECL=133)
//SYSPRINT DD SYSOUT=*
```

```bash
# List all datasets
fromjcl job.jcl --to json | jq -r '.steps[].dds[].datasets[]?.dsn'
PROD.SALES.EXTRACT
PROD.SALES.HISTORY
PROD.SALES.SORTED
PROD.SALES.SORTED
PROD.DAILY.REPORT

# Which datasets are created?
fromjcl job.jcl --to json | jq -r '.steps[].dds[].datasets[]? | select(.disposition.status=="NEW") | .dsn'
PROD.SALES.SORTED
PROD.DAILY.REPORT

# Total space requested (cylinders)
fromjcl job.jcl --to json | jq '[.steps[].dds[].datasets[]?.space | select(.type=="CYL") | .primary] | add'
100
```

## Example: Daily Batch Processing

The ZOAU converter recognizes common IBM utilities and emits native commands instead of wrapping everything in `mvscmd`.

**Input JCL** (`dailyrun.jcl`):
```jcl
//DAILYRUN JOB (ACCT001),'DAILY BATCH',CLASS=A,MSGCLASS=X,
//             NOTIFY=&SYSUID,MSGLEVEL=(1,1)
//*********************************************************************
//*  DAILY BATCH PROCESSING JOB
//*    1. Archive yesterday's output
//*    2. Create fresh work datasets
//*    3. Stage input data
//*    4. Clean up temporary files
//*********************************************************************
//ARCHIVE  EXEC PGM=IEBGENER
//SYSPRINT DD SYSOUT=*
//SYSIN    DD DUMMY
//SYSUT1   DD DSN=PROD.DAILY.OUTPUT,DISP=SHR
//SYSUT2   DD DSN=PROD.HISTORY.OUTPUT,DISP=SHR
//*
//SETUP    EXEC PGM=IEFBR14
//WORKPS   DD DSN=WORK.DAILY.DATA,
//            DISP=(NEW,CATLG,DELETE),
//            SPACE=(TRK,(50,10)),
//            DCB=(RECFM=FB,LRECL=80,DSORG=PS)
//WORKPDS  DD DSN=WORK.DAILY.TEMP,
//            DISP=(NEW,CATLG,DELETE),
//            SPACE=(CYL,(5,2,10)),
//            DCB=(RECFM=FB,LRECL=133,DSORG=PO)
//*
//STAGE    EXEC PGM=IEBGENER
//SYSPRINT DD SYSOUT=*
//SYSIN    DD DUMMY
//SYSUT1   DD *
PROCESS DATE=CURRENT
REGION=NORTHEAST
CUSTOMER_TYPE=PREMIUM
DEBUG=NO
MAX_RECORDS=10000
OUTPUT_FORMAT=STANDARD
/*
//SYSUT2   DD DSN=WORK.DAILY.CONTROL,DISP=SHR
//*
//CLEANUP  EXEC PGM=IDCAMS
//SYSPRINT DD SYSOUT=*
//SYSIN    DD *
 DELETE 'WORK.TEMP.SCRATCH'
 DELETE 'WORK.TEMP.WORK001'
 DELETE 'WORK.TEMP.WORK002'
 SET MAXCC=0
/*
```

**Convert to ZOAU** (`fromjcl dailyrun.jcl --to zoau`):
```bash
#!/bin/sh
# Generated by fromjcl --to zoau
# Job: DAILYRUN

# Step: ARCHIVE
# Copy dataset
dcp "PROD.DAILY.OUTPUT" "PROD.HISTORY.OUTPUT"

# Step: SETUP
# DD WORKPS: Allocate dataset
dtouch -tseq -l80 -rFB -s50T "WORK.DAILY.DATA"
# DD WORKPDS: Allocate dataset
dtouch -tpds -l133 -rFB -s5C "WORK.DAILY.TEMP"

# Step: STAGE
# Write instream data to dataset
echo 'PROCESS DATE=CURRENT
REGION=NORTHEAST
CUSTOMER_TYPE=PREMIUM
DEBUG=NO
MAX_RECORDS=10000
OUTPUT_FORMAT=STANDARD
' | decho "WORK.DAILY.CONTROL"

# Step: CLEANUP
# IDCAMS DELETE
drm "WORK.TEMP.SCRATCH"
drm "WORK.TEMP.WORK001"
drm "WORK.TEMP.WORK002"
```

**Supported utility conversions:**

| JCL Utility | ZOAU Command |
|-------------|--------------|
| IEBGENER (copy) | `dcp` |
| IEBGENER (instream) | `echo \| decho` |
| IEFBR14 (allocate) | `dtouch` |
| IEFBR14 (delete) | `drm` |
| IDCAMS DELETE | `drm` |
| IEBCOPY | `dcp` |
| ISRSUPC | `ddiff` |
| IEHLIST LISTPDS | `mls` |
| IEHPROGM SCRATCH | `drm` / `mrm` |
| IEHPROGM RENAME | `dmv` / `mmv` |

Utilities without ZOAU equivalents fall back to `mvscmd` automatically.

## Python API

```python
from fromjcl import parse, Job

job = Job.from_parsed(parse("test.jcl"))

print(f"Job '{job.name}' has {len(job.steps)} step(s):")
for step in job.steps:
    dd_names = [dd.name for dd in step.dds]
    print(f"  {step.name} runs {step.program} with DDs: {', '.join(dd_names)}")
```

```
Job 'TESTJOB' has 1 step(s):
  STEP01 runs IDCAMS with DDs: SYSPRINT, SYSIN
```
