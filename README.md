# fromjcl

Convert JCL to modern formats.
```
fromjcl job.jcl --to ansible    # Ansible playbook
fromjcl job.jcl --to mvscmd     # Shell script for z/OS USS
fromjcl job.jcl --to json       # Structured JSON
fromjcl job.jcl --to yaml       # Structured YAML
```

## Example

Input (`job.jcl`):
```jcl
//COPYJOB  JOB (ACCT),'COPY DATA',CLASS=A,MSGCLASS=X
//STEP01   EXEC PGM=IEBGENER
//SYSPRINT DD SYSOUT=*
//SYSIN    DD DUMMY
//SYSUT1   DD DSN=MY.INPUT.FILE,DISP=SHR
//SYSUT2   DD DSN=MY.OUTPUT.FILE,DISP=SHR
```

Output (`fromjcl job.jcl --to ansible`):
```yaml
- name: Execute JCL job COPYJOB
  hosts: zos_host
  gather_facts: false
  tasks:
  - name: Step STEP01 - IEBGENER
    ibm.ibm_zos_core.zos_mvs_raw:
      program_name: IEBGENER
      dds:
      - dd_output:
          dd_name: SYSPRINT
          return_content:
            type: text
      - dd_dummy:
          dd_name: SYSIN
      - dd_data_set:
          dd_name: SYSUT1
          data_set_name: MY.INPUT.FILE
          disposition: shr
      - dd_data_set:
          dd_name: SYSUT2
          data_set_name: MY.OUTPUT.FILE
          disposition: shr
```

Output (`fromjcl job.jcl --to mvscmd`):
```bash
#!/bin/sh
# Generated by fromjcl
# Job: COPYJOB

# Step: STEP01
mvscmd \
    --pgm=IEBGENER \
    --sysprint=* \
    --sysin=dummy \
    --sysut1=MY.INPUT.FILE \
    --sysut2=MY.OUTPUT.FILE
```

## Installation
```bash
pip install fromjcl
```

## Python API
```python
from fromjcl import parse, Job
from fromjcl.converters import mvscmd, ansible

job = Job.from_parsed(parse("job.jcl"))

# Inspect
for step in job.steps:
    print(f"{step.name}: {step.program}")

# Convert
print(ansible.convert(job))
print(mvscmd.convert(job))
```
